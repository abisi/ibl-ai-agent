# ssl-dlc-utils-validation

Validation of the DLC module `ephys_utilities/helpers/dlc_helpers.py` and of the DLC data in the NWB_ks4 files (AB / MH
mice), before dependent analyses switch to the module. Question: `question.md`; open items: `TODO.md`; history:
`change-log.md`.

- Results (tables, figures, caches): `combined_results_ks4/ssl-dlc-utils-validation/{tables,figures,cache}`
  (haas `/mnt/lsens-analysis/Axel_Bisi/...`, PC `M:\analysis\Axel_Bisi\...`).
- Report (LaTeX article, PDF + md + html): `combined_results_ks4/ssl-dlc-utils-validation/report/`, generated by
  `report/build_report.py` (haas) and rendered by `report/render.sh` (PC).
- Script numbers key the result files (`tables/<nnn>_*.csv`, `figures/<nnn>_*.png`); scripts were moved into sections
  on 2026-11-10 without renumbering. Figures 009, 016 and 017 in the result folder come from one-off checks without a
  saved script.

## Layout

All scripts import `exploratory-analyses/common.py` (paths, the 12-session sample, `dlc_helpers` import); each script
adds that folder to `sys.path` itself. Run on haas with `nice -n 10 ~/code/ibl-ai-agent/.venv/bin/python <script>`.

| Section (folder under `exploratory-analyses/`) | Script | Question |
|---|---|---|
| `1_units_reference_scale/` | `000_units_and_rates.py` | Physical units and frame rates of the NWB DLC series; stored `*_velocity` per second, not rate-multiplied twice by the loader; velocity vs speed |
| | `001_reference_point.py` | Jaw / nose reference point at the image origin (converter, too many low-likelihood frames): stored vs recomputed (`fix_zero_reference`) |
| | `004_rig_scale.py` | Which rig (camera scale, px/mm) each session was recorded on: body-feature sizes in pixels, probe sheet |
| `2_likelihood_and_cleaning/` | `002_cleaning_steps.py` | What each cleaning step (likelihood mask, jump, MAD, gap interpolation, smoothing) does to traces and event-locked means |
| | `005_jaw_likelihood_frames.py` | Is the jaw well placed when its likelihood is low? (jaw not gated by likelihood) |
| | `007_keypoint_likelihood_frames.py` | Pupil, whisker, nose keypoints per likelihood bin: where tracking breaks down (cutoff 0.1) |
| `3_lick_times/` | `003_dlc_lick_times.py` | DLC lick times (video clock in the NWB) to session time: per-frame timestamps vs a single offset, against piezo licks |
| `4_top_view_and_video_audit/` | `008_top_orientation_frames.py` | Top-camera orientation per session (setup 2 mounted upside down), one frame per session |
| | `018_video_dlc_audit.py` | Per session and camera: video, DLC h5 and NWB series present and consistent (frames, pulses) |
| | `019_failed_top_dlc_frames.py` | The upside-down setup-2 sessions whose top DLC failed: frames with keypoints, likelihoods |
| `5_pupil/` | `013_pupil_frames.py` | What the pupil points look like at typical frames and at pupil-area spikes |
| | `014_pupil_qc_clean.py` | Day-0 pupil area with the pupil QC (`clean_pupil`) vs the stored trace; outlier mice |
| | `015_pupil_review.py` | Review of candidate outlier mice on tracking quality only |
| `6_event_overviews/` | `010_event_triggered_overview.py` | Event-triggered DLC traces (licks, whisker, auditory) for all sessions with DLC, through the module |
| | `011_day0_posture_movement.py` | Day-0 posture and movement per body part and trial type, R+ and R- |

## Run order

Sections are independent; within a section run in number order. Dependencies: 007 loads helpers from 005 (same
folder); 014 and 015 import 011 (`6_event_overviews/`); 015 imports 013. 010, 011 and 014 write caches
(`cache/<nnn>_<session>.npz`) and accept `--plot-only`.

Outputs per script are listed in each script's docstring.
